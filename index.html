Algorithm notes

Why comb sort helps

Bubble sort's slow spot
Bubble sort only swaps neighbors, so a badly misplaced value can need one pass for every position it must travel.
Comb sort's gap
Comb sort compares values that are farther apart first. That lets distant out-of-place records move much closer to home in one swap.
Shrinking toward one
Each pass divides the gap by 1.3 until the gap reaches one, at which point the algorithm behaves like a final bubble-sort cleanup pass.
Prepared offline, replayed in-browser
Python fetches market data, computes returns, records every comparison, and writes JSON files. The website only replays that recorded sequence.
